## 15-minute demo script (screen share)

1. **`/schools`** — Value props: structured paths, teacher visibility, async delivery. Point to feature list (600+ questions, manager dashboard).
2. **`/schools/curriculum`** — Three tracks; **only Part 107 is live**. Sample questions and teacher-resource framing.
3. **`/schools/funding`** — PA SMART / Perkins language; **never promise eligibility**.
4. **Live product (needs admin/demo login)** — Log in as demo student: course units, progress, practice exam.
5. **`/manager`** (manager role) — Cohort progress, member activity — **this closes most school deals**.
6. **`/consultation`** — How they book if not ready on the call.

If you lack demo credentials, stop at public pages and schedule a product walkthrough with the founder.

## Qualification (ask on every call)

**Program**

- Part 107, media, AI/STEM, or mixed pathway?
- High school, CC, workforce, adult?
- How many students year one? How many sections?
- Target start semester?

**Process**

- Who signs? Who pays? Grant vs CTE vs general fund?
- PO required? Vendor onboarding? Legal/privacy review?
- Board approval timeline?

**Exit**

- **Qualified → quote** within 2 business days
- **Needs info →** send recap + links
- **Nurture →** set 90-day follow-up
- **Not a fit →** close politely

Full checklist: [`outreach.md`](../../workflows/sales/outreach.md) § Qualification checklist.

## Objection handling (short)

| Objection | Response |
|-----------|----------|
| “We already use YouTube / a workbook.” | Structured path + progress + exams + teacher dashboard; async hybrid; not replacing flight lab — supplementing knowledge test prep. |
| “How do we know students will pass?” | Honest prep depth (600+ practice items); we do **not** quote pass rates. Offer pilot tier. |
| “We need LMS / Google Classroom.” | Browser-based today; SSO/LTI on roadmap — ask what integration is blocking vs nice-to-have. |
| “Can this fit our grant?” | Share funding page; they confirm with grants office; we provide program description language, not eligibility guarantees. |
| “What about drones / lab equipment?” | Content is software; hardware is separate; we can discuss lab partners offline — don’t bundle hardware promises. |
| “Price too high / no budget.” | Pilot tier, smaller seat cap, nurture to next fiscal/grant cycle. |
| “We need Video/AI track now.” | Part 107 live; other tracks coming — don’t sell unfinished SKUs. |

More context: [`competitor-analysis.md`](competitor-analysis.md).

## After the call

Within **1 business day**, send recap email ([`outreach.md`](../../workflows/sales/outreach.md) § Post-call recap):

- Program summary, student count, timing, tracks
- Links (schools, curriculum, funding, privacy, legal)
- Clear next step: quote / follow-up / nurture

If qualified, draft quote using [`quote-template.md`](quote-template.md) and get **leadership approval** before sending formal pricing.

## CRM / tracker (minimum)

Use spreadsheet or CRM with fields from [`outreach.md`](../../workflows/sales/outreach.md) § Contact tracker schema:

**Must-have:** Organization, contact, role, status, next follow-up, owner, student count, funding notes, links sent.

**Stages:** Researched → Ready → Emailed → Replied → Meeting booked → Qualified → Quoted → Won / Lost / Nurture
