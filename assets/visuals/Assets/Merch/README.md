# Merch artwork — Drone Edge tees

**Full plan (blanks, shops, which concept to print first):** [`docs/marketing/merch.md`](../../../../docs/marketing/merch.md).

Print-ready white artwork for black garments, plus flat tee mockups. Generated by
[`scripts/build_merch_art.py`](../../../../scripts/build_merch_art.py) from the brand SVGs in
[`assets/visuals/Logo/`](../../Logo/); re-run the script to change sizes or add placements.

- `print/` — one design per placement. **`.svg`** is true-size vector (inches in the file, all
  text outlined, no fonts needed). **`.png`** is the same art at 300 DPI, white on transparent.
- `mockups/` — six shirt concepts on a flat black tee (size M proportions) at true scale.
- `print-files-preview.png` — all print files on a dark background for quick review.

Fonts used for added text: Chakra Petch SemiBold (tagline), Space Mono Regular (URL).
Wordmark and icon are the official logo paths, untouched.

## Uploading

- **Local shop (screen print / embroidery):** send the `.svg` (or the matching `.png` if they
  ask for raster). State the size from the table so nothing gets rescaled. For embroidery, ask
  for white thread, black 2.0–2.5 oz cutaway backing; icon-only files are the safe embroidery
  choice — wordmark letters need to be ≥ 0.3 in tall (the 10 in and 12 in lockups qualify,
  the 4 in left-chest lockup is print-only).
- **Blankstyle / online printers:** upload the `.png` (transparent, 300 DPI). Set the print
  size to the width in the filename.
- **DTF gang sheet (DTFhub, Custom Print House, DTFNJ):** drop the `.png` files into the gang
  sheet builder at their filename widths. A 22 × 12 in sheet holds ~12 left-chest icons or
  ~20 sleeve icons.
