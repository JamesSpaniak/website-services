# Newsletter issues — Drone Edge Field Notes

One markdown file per issue: `YYYY-MM.md` (e.g. `2026-11.md`), copied from [`_template.md`](_template.md).

- Strategy, sections and rules: [`docs/marketing/newsletter-plan.md`](../../docs/marketing/newsletter-plan.md)
- Send steps: [`workflows/marketing/newsletter.md`](../../workflows/marketing/newsletter.md)

Upload the **whole file** (front matter included) in **Admin → Newsletter** — locally to preview, on the live site to approve and send. The `slug` in the front matter decides which issue an upload updates; re-upload to change a draft, or (after send) add `correction:` to fix the web copy. These files are the drafting source and git history; the site's `newsletter_issues` table is the record of what was approved and sent.
