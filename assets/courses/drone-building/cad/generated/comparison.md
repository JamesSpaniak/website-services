Reading the table: CG below the prop plane and larger inertia = calmer, slower response; higher authority = snappier. Roll peak/settle are from one fixed controller gain set flown on every frame, so differences are the frame's. Arm SF is for the flat-printed orientation; the standing-print number in each report is 40–50 % lower for PLA/PETG. Cam→prop = smallest angle between the camera axis and a front prop (O4 sees ±77.5°; bigger is better).
